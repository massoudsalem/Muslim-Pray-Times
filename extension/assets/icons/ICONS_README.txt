Quick start: copy the existing icon from the Firefox extension and resize it:

  Source: ../../../firefox/icons/pray-times-48.png

You can use any image editor, online tool (e.g. favicon.io), or ImageMagick:

  magick pray-times-48.png -resize 16x16 icon-16.png
  magick pray-times-48.png -resize 32x32 icon-32.png
  magick pray-times-48.png              icon-48.png
  magick pray-times-48.png -resize 128x128 icon-128.png
